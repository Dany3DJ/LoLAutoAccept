# LoLAutoAccept
🎮 Automatically accepts your game queue for you so you can
  🚽 Take a quick bathroom break without missing the match  
  💧 Grab some water and stay refreshed  
  🌿 Step outside and touch some grass for a minute  
  ✅ No more stress over that annoying “Accept” prompt

How to make it work? Its quite simple.
  1- Download the .exe file.
  2- Run it as an admin
  3- It will accept your queue when the accept prompts.

Sounds fishy? You are correct.
But unfortunately the script did not work with the league client when not given admin privilege.
So, I will be attaching the source code for the script here and you can run it yourself either through a python env or build it into an exe if you prefer.
